## 1. Название

**Модернизация сайта медицинского центра «Вега-М»: SEO, аналитика и автообновляемый прайс-лист.**

Проект объединяет техническое SEO, подключение аналитики, ускорение сайта и автоматизацию прайса на основе данных МИС «Архимед».

---

## 2. Проблема

Сайт клиники существовал и принимал пациентов, но работал ниже своих возможностей.

- **Сайт плохо понимался поисковиками.** У 50 страниц название в поиске было одинаковым — только «| Медицинский центр ВЕГА-М». У 54 страниц отсутствовало описание. На страницах не было главного заголовка H1. Человек в выдаче не понимал, о чём страница, и не переходил на неё.
- **Дубли и битые ссылки.** Существовали две почти одинаковые страницы гастроэнтеролога, а в трёх статьях ссылки вели на несуществующие адреса. Поисковик не знал, какую страницу показывать, а посетитель видел ошибку.
- **Не было аналитики.** Клиника не могла узнать, сколько людей заходит на сайт, откуда они приходят и сколько звонят. Решения принимались «на глаз».
- **Прайс-лист был PDF-файлом.** Чтобы обновить цены, файл нужно было вручную пересобрать и заменить. Цены устаревали, расходились с МИС и заставляли пациентов звонить уточнять стоимость.
- **Сайт был медленным.** Главная страница содержала около 8 МБ изображений, страница «Врачи» — 6,4 МБ. Одно фото врача весило 2,3 МБ. На телефоне сайт открывался около 8 секунд, и часть людей уходила, не дождавшись загрузки.
- **Данные организации были заполнены не полностью** — в поиске, соцсетях и Яндекс.Бизнесе.

Почему это важно: для медицинской клиники сайт — точка входа пациента. Если сайт медленный, непонятный в поиске и показывает неактуальные цены, клиника теряет звонки и записи, а администраторы тратят время на одни и те же вопросы.

## 3. Пользователь

**Основной пользователь — пациент клиники:**

- житель Сергиева Посада и соседних районов Московской области;
- ищет врача, УЗИ, анализы, прививки или процедуры;
- чаще всего заходит с телефона;
- сравнивает цены и выбирает клинику по информации из поиска, карт и сайта.

**Внутренние пользователи:**

- **администраторы клиники** — им важно, чтобы пациенты видели актуальные цены и реже звонили с вопросом «сколько стоит»;
- **руководство клиники** — нужна понятная статистика: сколько людей приходит, откуда и сколько звонит;
- **сотрудник, отвечающий за сайт** — получает инструменты для обновления цен и управления страницами без пересборки PDF.

## 4. Основная функция

Проект приводит сайт в порядок по трём направлениям: **поиск**, **цены** и **скорость**.

### Вход

- доступ к сайту через админку WordPress;
- резервная копия сайта и базы;
- данные МИС «Архимед» (SQL Server): услуги, цены, группы, привязка услуг к врачам, коды МЗ;
- тексты названий и описаний для 143 страниц (Excel/CSV);
- результаты SEO-аудита и замеров скорости.

### Обработка — что делает проект

1. **Проводит аудит** всех страниц: названия, описания, заголовки H1, дубли, битые ссылки, карта сайта, скорость.
2. **Готовит и внедряет метаданные:** шаблоны title для записей, страниц и услуг; 113 описаний для страниц, где они были пустыми или длиннее 160 символов.
3. **Добавляет H1** на 24 из 26 страниц и на главную — без изменения внешнего вида сайта.
4. **Убирает дубли:** 301-редирект с дубля гастроэнтеролога и со старых рубрик на новые разделы; исправляет 3 битые ссылки.
5. **Подключает аналитику:** счётчик Яндекс.Метрики, цель «Клик по телефону», исключение служебных визитов сотрудников; привязка к Яндекс.Вебмастеру, чистка карты сайта, отправка 20 приоритетных страниц на переобход.
6. **Автоматизирует прайс:** скрипт на ПК клиники выгружает цены из «Архимеда» и отправляет их на сайт; страница `/prays-list/` и блоки цен на страницах услуг обновляются сами.
7. **Сверяет цены** сайта с МИС: 432 позиции, отчёт о расхождениях, исправление найденных ошибок; проверка цен на всех 50 страницах врачей.
8. **Ускоряет сайт:** перевод 5 139 изображений в WebP, включение кэширования; главная — около 1,6–2 с вместо 8 с.
9. **Заполняет представление организации:** картинка для соцсетей 1200×630, граф знаний AIOSEO, карточка Яндекс.Бизнеса.
10. **Документирует результат:** SEO-отчёт, план исправлений, отчёт «было — стало», таблицы сверок, резервные копии.

### Выход

- обновлённый живой сайт;
- страница прайс-листа с поиском, кодом МЗ и версией для печати;
- ежедневно обновляемые цены на страницах услуг;
- работающие панели Метрики и Вебмастера;
- комплект отчётов и резервных копий.

## 5. Формат результата

- **Работающий сайт** с уникальными названиями и описаниями страниц, главными заголовками, без дублей и битых ссылок.
- **Страница прайс-листа** `/prays-list/`: поиск по названию и коду услуги, код МЗ, дата обновления, кнопка «Версия для печати». Цены обновляются автоматически каждый день из МИС «Архимед».
- **Блоки цен на страницах услуг** (кроме нарколога — по указанию клиники): код услуги, код МЗ, название, цена; при разных ценах у одной услуги — фамилия врача.
- **Автоматически обновляемые разделы:** анализы, УЗИ, функциональная диагностика, процедурный кабинет, прививки, телемедицина.
- **Статистика:** Яндекс.Метрика (посещения, источники, цель «Клик по телефону») и Яндекс.Вебмастер (индексация, карта сайта, переобход).
- **Заполненная карточка Яндекс.Бизнеса:** контакты, соцсети, режим работы, прайс-лист на 473 позиции.
- **Отчётность:** SEO-отчёт и план исправлений (Word/PDF), отчёт о работах (Word/PDF), наглядный отчёт «было — стало» (HTML/PDF), таблицы сверок (XLSX), таблица титлов и описаний для 143 страниц (Excel/CSV).
- **Резервные копии сайта и базы** — сохраняются; удаление только по прямой просьбе владельца.

## 7. Технологии

### Сайт и инфраструктура

| Слой | Технологии |
|---|---|
| CMS | WordPress |
| Тема | Astra |
| Конструктор | Elementor |
| SEO | All in One SEO (AIOSEO): title, описания, sitemap, граф знаний, соцсети |
| Сниппеты | Code Snippets: PHP для H1, редиректов, Метрики, цен и синхронизации |
| Изображения | Converter for Media (WebP, обходной путь Nginx) |
| Кэширование | WP Super Cache |
| Хостинг | REG.RU, Nginx |

### Интеграция с МИС

| Слой | Технологии |
|---|---|
| СУБД | Microsoft SQL Server (МИС «Архимед») |
| Обмен | REST API WordPress с секретным заголовком |
| Формат | JSON (~3,1 МБ): цены, коды МЗ, привязка врачей |

### Скрипты и данные

| Инструмент | Роль |
|---|---|
| PowerShell | Ежедневная выгрузка цен из SQL Server и загрузка на сайт; Планировщик Windows |
| Python | Аудит, сопоставление цен, генерация Excel/Word/PDF-отчётов |
| Node.js | Рендеринг PDF-прайса и превью |
| Браузерная автоматизация | Работа в админке WordPress через Microsoft Edge |
| Форматы | JSON, CSV, XLSX, DOCX, PDF, HTML |

### Аналитика и поиск

| Инструмент | Роль |
|---|---|
| Яндекс.Метрика | Посещения, источники, цель «Клик по телефону» |
| Яндекс.Вебмастер | Индексация, карта сайта, переобход |
| Яндекс.Бизнес | Карточка организации |
| schema.org | Разметка Organization через AIOSEO |

### Надёжность

| Инструмент | Роль |
|---|---|
| UpdraftPlus | Резервные копии сайта и базы |
| Правило проекта | Резервные копии не удаляются |

## Безопасность публикации

В репозитории **нет**:

- паролей, токенов и ключей доступа;
- строк подключения к базам данных и внутренних IP-адресов;
- названий внутренних таблиц и представлений МИС;
- персональных данных пациентов и сотрудников;
- служебных email и ссылок на админку.

Репозиторий содержит только описание кейса. Исходные скрипты, доступы и рабочие конфигурации не публикуются.
